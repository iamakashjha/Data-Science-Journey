# Student Performance Management System

## Overview

A Python application for managing student performance data.

## Features

- Add students
- Display student information
- Calculate averages
- Assign grades
- Find class topper
- Search students
- Save data to JSON
- Load data from JSON
- Handle invalid input

## Concepts Demonstrated

- Python data structures
- Functions
- Loops
- Conditional statements
- Exception handling
- File handling
- Modules
- Object-Oriented Programming
