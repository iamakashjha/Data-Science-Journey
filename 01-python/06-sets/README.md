# Day 34 – Python Sets: Working with Unique Data

Today you'll learn Sets, one of the most useful data structures for data cleaning and exploratory data analysis (EDA).

The biggest idea behind a set is simple:
```
A set stores only unique values.
```
This is incredibly useful when you're working with messy, real-world datasets.


### Learning Objectives

By the end of today, you should be able to:

- Create and use sets
- Understand why sets remove duplicates
- Add and remove elements
- Perform set operations
- Use sets for data cleaning
- Know when to use a set instead of a list
