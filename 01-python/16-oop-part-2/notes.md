### Data Science Connection

```
Imagine Scikit-learn models:

LinearRegression()

DecisionTreeClassifier()

RandomForestClassifier()
```

All of them provide methods like:

```
model.fit(X, y)

model.predict(X)
```

Even though the algorithms are different, they expose the **same interface.**

This is a real-world example of **polymorphism.**

Similarly, many machine learning models inherit common functionality from shared base classes.
