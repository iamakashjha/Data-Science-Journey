### 1. What is a variable?
Variable is a label and container in which we store something.

### 2. Why do data types matter?
Data types matters because we have data in different-different formats, if we will not choose the correct data type then we will not able to use the essence of the data.

### 3. When would I use int vs float?
We will use int if we have data without decimal and vice-versa.

### 4. Why does input() return a string?
Because string can store almost any data type.
