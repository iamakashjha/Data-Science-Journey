### 1. Difference between for and while loops?
- A for loop is used when we know how many times we want to iterate or when we are iterating over a sequence like a list, tuple, string, dictionary, or range().
- A while loop is used when the number of iterations is unknown and the loop continues until a condition becomes false.

### 2. When would you use a while loop instead of a for loop?
I use a while loop when I don't know in advance how many times the loop needs to run. The loop continues until a specific condition is met.

### 3. What is range()?
range() is a built-in Python function that generates a sequence of numbers. It is commonly used with for loops.

### 4. Difference between break and continue?
- break immediately exits the loop.
- continue skips the current iteration and moves to the next iteration.

### 5. Why are loops important in Data Science?
Loops are important because they allow us to automate repetitive tasks. In Data Science, we use loops to:

- Process large datasets.
- Clean and transform data.
- Apply operations to multiple rows or columns.
- Train or evaluate models over multiple iterations.
- Automate repetitive workflows.

**Note:** In libraries like Pandas and NumPy, we often prefer vectorized operations over loops because they are much faster. However, understanding loops is still essential for solving many programming problems and writing custom logic.
