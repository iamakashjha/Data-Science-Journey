# Day 43 – Object-Oriented Programming (OOP) Part 1: Classes & Objects

Welcome to Day 43!

So far, you've learned how to solve problems using variables, loops, functions, files, and exceptions. As programs become larger, organizing code with only functions becomes difficult.

This is where **Object-Oriented Programming (OOP)** helps.

OOP allows you to model real-world entities—such as students, customers, bank accounts, or datasets—as objects with both **data (attributes)** and **behavior (methods)**.

Many popular Python libraries used in Data Science, including **Pandas, Scikit-learn, and TensorFlow**, are built using OOP concepts.
