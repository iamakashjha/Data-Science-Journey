### 1. What is Object-Oriented Programming?
Object-Oriented Programming (OOP) is a programming style where code is organized into classes and objects. It helps make programs modular, reusable, and easier to manage.

### 2. What is the difference between a class and an object?
A class is a blueprint or template for creating objects, while an object is an instance of that class. The class defines the structure, and the object stores actual data.

### 3. What is the purpose of the __init__() method?
The __init__() method is a special method called automatically when an object is created. It is used to initialize the object's attributes and set up its starting state.

### 4. What does self represent?
Self represents the current instance of the class. It is used to access attributes and methods of that specific object.

### 5. What is the difference between an attribute and a method?
An attribute is a data value stored in an object, such as a name or age. A method is a function defined inside a class that performs actions using that object’s data.
