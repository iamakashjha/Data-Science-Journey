# Day 36 – Control Flow: if, elif, and else

Welcome to Day 36!

So far, your Python programs have stored data and manipulated collections.

Today, your programs start making decisions.

This is a major milestone because almost every Data Science workflow contains decision logic:

- Is a value missing?
- Is a customer high-value?
- Is a transaction suspicious?
- Should a prediction be accepted?


### Learning Objectives

By the end of today, you should be able to:

- Write if, elif, and else statements
- Use comparison and logical operators inside conditions
- Build nested conditions
- Apply decision-making to Data Science scenarios
