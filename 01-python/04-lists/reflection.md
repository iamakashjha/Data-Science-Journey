## What did I learn today?
Today I learned about Python lists, how they store multiple values in a single variable, and how to access, modify, add, and remove elements using different list methods.

## Which list method seems most useful?
The append() method seems the most useful because it allows me to easily add new elements to the end of a list, which is very common when collecting or processing data.


## How are lists used in Data Science?
Lists are used to store and organize datasets, hold feature values, collect results, and prepare data before converting it into libraries like NumPy arrays or pandas DataFrames for analysis and machine learning.
