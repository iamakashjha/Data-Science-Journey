### 1. What is a list?
A list is a Python data type that stores an ordered collection of elements. Lists can contain different data types (numbers, strings, booleans, even other lists) and are mutable, meaning they can be modified after creation.


### 2. Difference between lists and strings?
- Lists are mutable, meaning their elements can be changed.
- Strings are immutable, meaning their characters cannot be changed after creation.
- Lists can store different data types, whereas strings store only characters.


### 3. Why are lists mutable?
Lists are mutable because Python is designed to allow adding, removing, or modifying elements without creating a new list. This makes lists efficient for storing data that changes over time.


### 4. Difference between append() and insert()?
- `append()` adds an element to the end of the list.
- `insert(index, element)` adds an element at a specific index.

### 5. Difference between remove() and pop()?
- `remove(value)` removes the first occurrence of a specified value from the list and returns nothing.
- `pop(index)` removes and returns the element at the given index. If no index is provided, it removes and returns the last element.


### 6. Why are lists important in Data Science?
Lists are important in Data Science because they are used to store and organize collections of data. They are often the starting point before converting data into NumPy arrays or Pandas DataFrames for efficient numerical computation and analysis.
