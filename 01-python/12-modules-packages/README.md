# Day 40 – Modules & Packages: Organizing Python Projects

Congratulations on reaching Day 40! 🎉

Until now, you've written all your code in a single file. That works for small programs, but real Data Science projects often contain **dozens or hundreds of Python files.**

Today's lesson is about organizing your code professionally using **modules** and **packages**.

### 🎯 Learning Objectives

By the end of today, you should be able to:

- Understand what modules and packages are
- Import built-in modules
- Create your own modules
- Import functions from your own files
- Organize Python projects professionally
- Understand why modular programming is important
