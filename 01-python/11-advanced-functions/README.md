# Day 39 – Advanced Functions & Writing Professional Python

Welcome to Day 39!

Yesterday, you learned how to write reusable functions.

Today, you'll learn how to write functions **the way professional Python developers and Data Scientists do**.

By the end of today, you'll know how to make your functions:

- More flexible
- Easier to understand
- Better documented
- Easier to maintain

These are the same practices you'll see in libraries like **NumPy**, **Pandas**, and **Scikit-learn**.


### 🎯 Learning Objectives

By the end of today, you should be able to:

- Use positional and keyword arguments
- Understand default arguments
- Use *args and **kwargs
- Write docstrings
- Add type hints
- Understand recursion
- Follow function best practices
