### 1. What is string indexing?
String indexing is the process of accessing a specific character in a string using its position (index). In Python, indexing starts from 0.


### 2. Difference between indexing and slicing?
- Indexing returns a single character from a string.
- Slicing returns a portion (substring) of the string using a range of indices.


### 3. Why are strings immutable?
Strings are immutable because once a string is created, its contents cannot be changed. If you modify a string, Python creates a new string object instead of changing the existing one. This makes strings safer and more memory-efficient.


### 4. Difference between split() and replace()?
- `split()` divides a string into a list of substrings based on a separator.

- `replace()` returns a new string where specified text is replaced with another text.


### 5. Why are f-strings preferred?

F-strings are preferred because they are more readable, concise, and faster than string concatenation or the format() method. They allow variables and expressions to be embedded directly inside a string.
