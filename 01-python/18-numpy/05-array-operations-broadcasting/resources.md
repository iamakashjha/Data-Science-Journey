## Vocabulary

- **Element-wise:** an operation performed on corresponding values.
- **Vectorization:** whole-array computation without an explicit Python loop.
- **Broadcasting:** NumPy's shape-alignment mechanism for compatible arrays.
- **Boolean mask:** Boolean values used to filter an array.
- **Scalar:** a single numeric value, such as `10`.
- **Feature vector:** one value per feature, often shaped `(number_of_features,)`.
