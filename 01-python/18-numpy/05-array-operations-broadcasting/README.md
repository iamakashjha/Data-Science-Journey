# Day 50 - NumPy Array Operations and Broadcasting

This lesson introduces vectorized arithmetic, Boolean masks, and broadcasting in NumPy.

## Learning objectives

- Perform element-wise arithmetic and comparisons.
- Use vectorization instead of explicit Python loops.
- Filter arrays with Boolean masks.
- Explain scalar, row, and column broadcasting.
- Determine whether two shapes are broadcast-compatible.
- Apply broadcasting to simple data-science transformations.

## Files

- `theory.md` - Concepts and examples.
- `notes.md` - Short reference notes.
- `implementation.py` - Runnable demonstrations.
- `exercises.md` - Practice questions.
- `challenge.py` - Sales revenue mini-project.
- `reflection.md` - Understanding and self-assessment prompts.
- `resources.md` - Learning resources and key vocabulary.
