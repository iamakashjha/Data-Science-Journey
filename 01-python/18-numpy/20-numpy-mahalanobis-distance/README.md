# Day 66 — Mahalanobis Distance

This project implements multivariate anomaly detection
using Mahalanobis distance.

## Objectives

- Understand covariance
- Calculate Mahalanobis distance
- Implement vectorized distance calculation
- Detect multivariate anomalies
- Handle singular covariance matrices
- Build a reusable detector

## Structure

- theory.md
- notes.md
- implementation.py
- exercises.md
- challenge.py
- reflection.md
- resources.md

## Main Formula

D_M(x) = sqrt((x - μ)^T Σ^-1 (x - μ))
