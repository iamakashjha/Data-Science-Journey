# Day 54 - NumPy Boolean Masking, Filtering & Conditional Selection

Today we move from data structure to intelligent data selection.

Boolean masking lets you select exactly the elements or rows that satisfy a condition, which is one of the most important skills in data science.

## Learning objectives

- Understand Boolean values and Boolean arrays.
- Use `array[condition]` for filtering.
- Combine conditions with `&`, `|`, and `~`.
- Use `np.where()` for conditional values and indices.
- Use `np.any()` and `np.all()` to summarize conditions.
- Replace values conditionally.
- Filter rows and columns using masks.
- Apply masking to real dataset questions.
