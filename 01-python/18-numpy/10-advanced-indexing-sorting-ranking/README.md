# Day 56 - Advanced Indexing, Sorting & Ranking in NumPy

This is the continuation of the existing NumPy topic on advanced indexing, ranking, and selection.

Today we move from:

"Give me the values that satisfy this condition."

toward:

"Give me the observations in a particular order, identify their positions, and retrieve the top/bottom observations efficiently."

## Learning objectives

- Understand advanced indexing in NumPy.
- Use integer-array indexing confidently.
- Understand `argsort()`.
- Distinguish `sort()` from `argsort()`.
- Sort along different axes.
- Retrieve top and bottom observations.
- Use `argmin()` and `argmax()`.
- Understand `partition()` and `argpartition()`.
- Rank observations.
- Combine sorting with multidimensional arrays.
- Apply these concepts to realistic data science problems.
