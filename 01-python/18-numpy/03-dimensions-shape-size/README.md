### Key Takeaways

Remember these five:

`ndim`  → number of dimensions  
`shape` → structure of the array  
`size`  → total number of elements  
`len`   → size of the first dimension  
`reshape` → change structure without changing element count

And the Machine Learning pattern:
```
X.shape = (samples, features)
```
For example:
```
(5000, 20)
```
means:
```
5000 samples
20 features
```
This simple understanding will save you a huge amount of debugging time later in your Data Science and MLOps journey.
