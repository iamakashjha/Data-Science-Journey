# Day 53 - NumPy Reshaping, Flattening, Stacking & Splitting

Welcome to Day 53.

Today you learn how to change the structure of arrays without changing their data. This is an essential skill in data science, machine learning, and preprocessing.

## Learning objectives

- Use `reshape()` to change array structure while preserving values.
- Understand `flatten()` and `ravel()`.
- Use `transpose()` and `.T` to swap axes.
- Combine arrays with `concatenate()`, `stack()`, `vstack()`, and `hstack()`.
- Split arrays with `split()`, `vsplit()`, and `hsplit()`.
- Interpret shapes for tabular data and machine learning.
- Prepare feature matrix `X` and target vector `y`.
