# Reflection - NumPy Random Numbers & Reproducibility

## Understanding

### What is pseudo-randomness?

Pseudo-randomness is a sequence generated by an algorithm that appears random but is reproducible if the same seed is used.

### What does `np.random.random()` generate?

It generates a floating-point random value in the range `[0, 1)`.

### What does `np.random.randint()` generate?

It generates random integers within a specified range.

### What does `np.random.normal()` generate?

It generates random values from a normal distribution centered at a given mean with a specified standard deviation.

### What does `np.random.choice()` do?

It randomly selects values from an array or list, with optional weighting and replacement settings.

## Reproducibility

### What is a random seed?

A random seed initializes the pseudo-random generator so the same sequence can be reproduced.

### Why is reproducibility important?

It allows experiments, debugging, model training, and research to be repeated and verified.

### Why isn't `42` a magical number?

It is just a common choice for a seed. Any documented seed value can be used as long as it is controlled and reproducible.

### What is the purpose of `default_rng()`?

It creates a dedicated random-number generator using NumPy's modern API, making random behavior easier to control.

### Why might independent random generators be useful?

They let different parts of a project use separate random streams without interfering with each other.

## Data science

### Where can randomness appear in machine learning?

In train/test splits, parameter initialization, sampling, augmentation, and optimization.

### Why can synthetic data be dangerous if its assumptions are unrealistic?

Because it may produce misleading patterns and unrealistic conclusions.

### Why might generated exam scores need to be constrained?

Because a normal distribution can create values outside realistic ranges such as negative scores or values above 100.

### Why should you distinguish synthetic assumptions from real-world evidence?

Because a model of synthetic data is not the same as confirmed behavior in the real world.
