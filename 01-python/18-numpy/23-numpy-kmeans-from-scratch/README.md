# Day 69 — K-Means Clustering from Scratch

## Objective
Implement K-Means clustering using NumPy without relying on scikit-learn.

## Files
- implementation.py
- challenge.py
- exercises.md
- theory.md
- notes.md
- reflection.md
- resources.md

## Features
- centroid initialization
- distance computation with NumPy broadcasting
- assignment to nearest centroid
- centroid update step
- convergence detection
- inertia calculation
- prediction on new observations

## Requirements
- Python 3
- NumPy

## Run
```bash
python challenge.py
```
