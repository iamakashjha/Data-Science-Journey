# Day 69 Exercises

## Exercise 1 — Manual Assignment
Given a dataset and two centroids, determine which centroid each sample is closest to.

## Exercise 2 — Centroid Update
Compute the mean of each cluster and derive the new centroid locations.

## Exercise 3 — Inertia
Calculate inertia manually and then with NumPy.

## Exercise 4 — Different K Values
Run K-Means with several values of `k` and compare inertia.

## Exercise 5 — Initialization Sensitivity
Repeat the same clustering problem with different random seeds and compare results.

## Challenge
Build a reusable K-Means model and compare inertia across multiple values of `k`.
