# Day 57 — End-to-End NumPy Analysis

## Objective

Apply previously learned NumPy concepts to a realistic data-analysis workflow.

## Topics

- Vectorization
- Data validation
- Derived metrics
- Boolean filtering
- Multiple conditions
- Statistics
- Ranking
- Top-k selection
- Outlier detection
- Normalization
- Feature scoring

## Dataset

Customer-level arrays:

- Customer ID
- Orders
- Revenue
- Returns

## Main questions

1. Which customers generate the most revenue?
2. Which customers generate the most revenue per order?
3. Which customers have high return rates?
4. Which customers satisfy multiple business conditions?
5. Which observations may be unusual?
6. How can multiple features be combined into an analytical score?

## Key learning

The goal is not to memorize NumPy functions.

The goal is to combine NumPy operations into a coherent analytical workflow.

## Files

- `theory.md` - conceptual summary of the analysis workflow
- `notes.md` - key concepts and patterns
- `implementation.py` - full end-to-end analysis demo
- `exercises.md` - practice questions
- `challenge.py` - customer intelligence report
- `reflection.md` - reflection prompts and interview questions
- `resources.md` - references and review topics
