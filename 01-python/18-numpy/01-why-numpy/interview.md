# 5 Interview Questions

### 1. What is NumPy?

**Answer:**

NumPy is a Python library for numerical computing. Its core feature is the multidimensional ndarray, along with efficient mathematical, statistical, random, and linear algebra operations.

### 2. What is the difference between a Python list and a NumPy array?

**Answer**:

A Python list is a general-purpose, flexible collection, while a NumPy array is designed for efficient numerical computation and supports vectorized operations and multidimensional data.

### 3. Why is NumPy generally faster than Python loops for numerical operations?

**Answer**:

NumPy operations are implemented using optimized compiled code and can process arrays in bulk, avoiding much of the overhead of executing individual numerical operations through Python loops.

### 4. What is vectorization in NumPy?

**Answer**:

Vectorization is the practice of applying an operation to an entire array without explicitly writing a Python loop.

**For example**:
```
arr * 2
```
applies multiplication to every element of arr.

### 5. What is ndarray?

**Answer**:

`ndarray` is NumPy's fundamental multidimensional array data structure. It stores elements in a structured numerical array and supports efficient mathematical and indexing operations.
