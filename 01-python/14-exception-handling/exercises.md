### 1. What is an exception?
An exception is an error that occurs while a program is running. Without exception handling, the program stops immediately.

### 2. Difference between try and except?
In try block we write our actual code which we have written to handle the logic, except block helps us in handling the error.

### 3. When does the else block execute?
The else block runs only if no exception occurs.

### 4. Why is finally useful?
The finally block always executes, whether an exception occurs or not.

### 5. What is the purpose of raise?
Using raise block we can create our custome exception. Sometimes your program should create an exception.

### 6. Why is exception handling important in Data Science?
Some rows contain missing or invalid values. Instead of stopping the entire program, you can skip bad rows and continue processing the rest of the dataset.
