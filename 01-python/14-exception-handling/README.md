# Day 42 – Exception Handling: Writing Robust Python Programs

Welcome to Day 42!

Until now, your programs worked only when everything went as expected. But in real applications, things can go wrong:

- A user enters text instead of a number.
- A file doesn't exist.
- A calculation divides by zero.
- A dataset contains missing values.

Instead of crashing, professional programs **handle these situations gracefully using exception handling.**
