# Data Science Connection

Imagine customer purchases:
```
purchases = [
    "Laptop",
    "Phone",
    "Laptop",
    "Tablet",
    "Phone",
    "Laptop"
]
```
Question:

- Which product is purchased most often?

A dictionary provides the answer quickly.

This idea is used in:

- Product analytics
- Word frequency analysis
- Log analysis
- Recommendation systems
