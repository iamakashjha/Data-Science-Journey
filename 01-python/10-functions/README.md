# 🚀 Day 38 – Functions: Writing Reusable Code

Welcome to Day 38!

So far, you've written Python programs from top to bottom. As your programs grow, repeating the same code becomes difficult to manage.

Today's lesson introduces one of the most important programming concepts:

**Functions let you write code once and reuse it many times.**

Functions are everywhere in Data Science. Whether you're cleaning data, calculating statistics, or training models, you'll constantly create and use functions.
