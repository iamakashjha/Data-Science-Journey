# Day 33 – Python Tuples: Immutable Data

Yesterday you learned lists, which are mutable collections. Today you'll learn tuples, which are immutable collections.

This may seem like a small difference, but choosing the right data structure is an important programming skill.

## 🎯 Learning Objectives

By the end of today, you should be able to:

- Understand what tuples are
- Compare tuples and lists
- Access tuple elements
- Use tuple methods
- Know when to use tuples instead of lists
- Understand tuple unpacking
