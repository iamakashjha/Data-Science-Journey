### 1. What was the biggest insight about vectors?

The biggest insight is that a **vector represents both magnitude and direction**, and in AI, vectors are used to represent data points where each component is a feature.

### 2. Why are datasets naturally matrices?

Datasets are naturally matrices because **each row represents an observation (or sample)** and **each column represents a feature (or variable)**, making the entire dataset a structured table of numbers.

### 3. What surprised you about matrix multiplication?

The most surprising aspect is that **matrix multiplication is not simple element-wise multiplication.** Each element of the result is computed by taking the **dot product of a row from the first matrix and a column from the second**, which is why compatible dimensions are required.

### 4. Where do you think you'll use dot products again?

Dot products are used extensively in:
- Machine Learning algorithms (e.g., Linear Regression, Logistic Regression)
- Neural Networks (calculating weighted sums)
- Similarity measures (Cosine Similarity)
- Recommendation systems
- Computer Vision and Natural Language Processing

### 5. Which linear algebra topic needs more revision?

**Eigenvectors** and **eigenvalues** need the most revision because understanding their intuition and applications in areas like **Principal Component Analysis (PCA)** and other machine learning algorithms takes more practice than basic vectors and matrices.
