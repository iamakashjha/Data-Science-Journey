# 2. Derivative
Derivative measures how fast something changes.

**Example:**
```
f(x)=x^2
```

- Derivative:
```
f′(x) = 2x
```

[derivative](/00-foundations/math/calculus/calculus-basics/derivative.png)


**Meaning:**  
- slope changes with x


**Real ML Connection**  
Machine learning models improve using:
* gradients
* derivatives
* optimization

This is how models “learn”.

# 3. Slope Intuition

Slope tells:
- how steep a graph is
- how fast values change  

Formula:  
```m = {y_2-y_1}/{x_2-x_1}```

# 4. Gradient Intuition
**Gradient tells:**
- which direction reduces error fastest

**Used in:**  
- Gradient Descent
- Neural Networks
- Deep Learning training

**Why This Matters**  
Every AI model updates itself using ideas like:  

```w_new = w_old−η∇J(w)```

This is the core idea behind training neural networks.
