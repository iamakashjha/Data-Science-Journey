# 1. What is Calculus?
**Calculus studies:**
- change
- movement
- growth
- optimization

**Example:**
- speed of car changing
- stock prices changing
- ML model improving

# 2. Derivative
Derivative measures how fast something changes.

**Example:**
```
f(x)=x^2
```

- Derivative:
```
f′(x) = 2x
```
**Meaning:**  
- slope changes with x


**Real ML Connection**  
Machine learning models improve using:
* gradients
* derivatives
* optimization

This is how models “learn”.

# 3. Slope Intuition

Slope tells:
- how steep a graph is
- how fast values change  

Formula:  
```m = {y_2-y_1}/{x_2-x_1}```

# 4. Gradient Intuition
**Gradient tells:**
- which direction reduces error fastest

**Used in:**  
- Gradient Descent
- Neural Networks
- Deep Learning training
