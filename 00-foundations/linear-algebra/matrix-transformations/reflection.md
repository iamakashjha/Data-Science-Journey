## Reflection Questions

### 1. What is a transformation?

A transformation is an operation that changes a vector or data by applying a matrix. It can change the vector's size, direction, position, or orientation.

### 2. How does a scaling matrix affect a vector?

A scaling matrix changes the magnitude (length) of a vector while keeping its direction the same (unless a negative scale factor flips its direction). It stretches or shrinks the vector along one or more axes.

### 3. Can a matrix change direction?

Yes. A transformation matrix can rotate, reflect, or shear a vector, which changes its direction. Not all matrices only scale vectors.

### 4. Where are matrix transformations used in AI?

Matrix transformations are used throughout AI, including:

Transforming input data in neural networks
Feature extraction and dimensionality reduction
Image processing and computer vision
Natural language processing using embeddings
Training models by updating weights

### 5. Why do neural networks repeatedly transform data?

Neural networks repeatedly transform data so that each layer learns more meaningful and abstract features. These successive transformations help convert raw input into a representation that makes tasks like classification, prediction, or generation easier and more accurate.
