# Reflection Questions

### 1. What is a matrix?
A matrix is a rectangular arrangement of numbers organized into rows and columns. It can represent data, transformations, or collections of vectors.

### 2. What do rows represent?
In many datasets, each row represents one observation, sample, or data point.

For example:
```
Age	Salary	Experience
25	40000	2
30	60000	5
```
Here, each row represents one person.

### 3. What do columns represent?
Columns represent features, variables, or attributes of the data.

In the previous example:

- Age is a feature.
- Salary is a feature.
- Experience is a feature.



### 4. Why are datasets matrices?
Datasets can be represented as matrices because they consist of rows and columns:

- Rows = observations (samples)
- Columns = features (variables)

This matrix representation allows computers and machine learning algorithms to perform efficient mathematical operations.

### 5. Where do matrices appear in AI?
Matrices appear everywhere in AI:

- **Datasets:** Data is stored as matrices.

- **Images:** An image is represented as a matrix of pixel values. For example, a 28 × 28 grayscale image is a 28 × 28 matrix.

- **Neural Networks:** Weights and activations are stored as matrices.

- **Word Embeddings:** Words are represented as vectors organized into matrices.

- **Computer Vision:** Images and convolution operations use matrices extensively.
