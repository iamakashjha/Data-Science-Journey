# Population vs Sample

**a.) Population**
The entire group you're interested in.

**b.) Sample**
A smaller subset used for analysis.

# Topic 2: Sampling

**Good samples should be:**
- random
- representative
- unbiased

# Topic 3: Hypothesis
A hypothesis is a claim you want to test.

Example:
```
New website design increases sales.
```

# Topic 4: Null Hypothesis (H₀)
Default assumption:
```
The new website design has NO effect.
```
