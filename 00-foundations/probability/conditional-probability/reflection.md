# Write answers in your own words.

1. What changes when we receive new information?
- The sample space changes when we receive a new information.

2. Why does the sample space change?
- Because new information changes the denominator.
3. What does "given that" really mean?
- give that means something already happend.
4. Why is conditional probability useful?
- It allows you to calculate the probability of an event given that another event has already occurred.
5. Where might I use it in Data Science?
- **Classification models:** It is the foundation of the Naive Bayes algorithm, used for spam filtering and sentiment analysis.

- **A/B Testing:** Calculating the probability that a user converts given they saw a specific version of a webpage.

- **Recommendation engines:** Predicting what a user will buy given their past purchase history.
