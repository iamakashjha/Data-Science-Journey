# Concept 1: What Is Probability?

Probability is a measure of uncertainty.

**Examples:**
1. Will it rain tomorrow?
2. Will a customer buy?
3. Will a loan default?
4. Will a model predict correctly?

# Concept 2: Sample Space

The set of all possible outcomes.

Coin toss:

S = {H, T}

Dice roll:

S = {1, 2, 3, 4, 5, 6}

Before solving any probability problem:

Always identify the sample space first.

# Concept 3: Events

An event is a subset of outcomes.

Example:

Roll a die.

Event A:
Getting an even number

A = {2, 4, 6}

# Concept 4: Classical Probability

Formula:
```
P(A)= Favorable Outcomes/Total Outcomes
```

**Example:**

Probability of rolling a 4:

1 favorable outcome  
6 total outcomes

**Result:**
```
1/6
```
