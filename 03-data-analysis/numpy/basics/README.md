# NumPy
**NumPy is the foundation of:**
- Pandas
- Machine Learning
- Deep Learning
- TensorFlow
- PyTorch

Almost every AI system uses NumPy concepts.

**NumPy helps us:**
- work with arrays
- perform fast calculations
- handle numerical data efficiently

## 1. Arrays
**Arrays are similar to Python lists but:**
- faster
- memory efficient
- optimized for math

**Example:** A=[1,2,3,4,5]

## 2. Array Shape
Shape tells dimensions of data.  

**Example:** Shape=(rows,columns)
